# 🎨 Bộ Sưu Tập 25 Theme UI Độc Đáo

## 1. **Neon Cyberpunk**
- **Concept & Cảm Xúc**: Tương lai cyberpunk, năng lượng cao, neon rực rỡ, cảm giác như đang ở trong game sci-fi
- **Bảng Màu Chủ Đạo**: 
  - Primary: `#00F5FF` (Cyan neon)
  - Secondary: `#FF00FF` (Magenta neon)
  - Accent: `#00FF41` (Green neon)
  - Background: `#0A0A0F` (Dark navy)
  - Text: `#FFFFFF`
- **Phong Cách Background**: Dark gradient với neon glow effects, grid pattern mờ, particles animation
- **Icon Style**: Line icons với neon glow, outline style, animated
- **UI Style**: Glassmorphism với neon borders, dark transparent cards
- **Hiệu Ứng Hover/Focus**: Neon glow pulse, border animation, scale transform
- **Cách Hiển Thị Ngày & Sự Kiện**: Neon borders, glow effects, holographic style
- **Biến Thể**: Dark only (không có light mode), có thể có "Ultra Bright" variant

## 📝 Ghi Chú Implementation

### Cấu Trúc Theme
Mỗi theme sẽ có:
- CSS variables trong `globals.css`
- Theme class (`.theme-{name}`)
- Light/Dark variants nếu có
- Custom animations và effects

### Ưu Tiên Implementation
1. **Phase 1**: Neon Cyberpunk, Pastel Dream, Minimalist Zen, Ocean Depths, Sunset Paradise
2. **Phase 2**: Forest Canopy, Lavender Fields, Midnight Galaxy, Cherry Blossom, Desert Mirage
3. **Phase 3**: Các theme còn lại

### Tính Năng Bổ Sung
- Theme preview trong selector
- Theme animation transitions
- Custom icon sets cho mỗi theme
- Background patterns và textures
- Sound effects (optional) cho một số theme đặc biệt
